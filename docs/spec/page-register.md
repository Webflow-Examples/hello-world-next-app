# Page & Metadata Register

**Source of truth:** `docs/Compremium_Estimate_SEO_Localisation_Social (final).xlsx`, sheet `Page & Metadata Register`.

Transcribed verbatim from the spreadsheet at project start. **Never edit a metadata column to suit the code.**
Every title tag, meta description, H1 and URL slug in this table is a claim surface subject to QARA/Regulatory
and Clinical/Medical review. A value changes only when that review clears it, as a specification change that
names its source. See `claims-guardrails.md` before using any value.

> Main categories and launch pages for compremium.ch with drafted metadata. PATTERN RULES: title tag ≤60 characters and unique; meta description 140-155 characters, written as a description of the page, never as a claim; one H1 per page carrying the clinical question or the entity name; slug in lower-case English, no claim, no outcome verb, no date. STATUS COLUMN: LOW gate pages may be produced now. MEDIUM requires Product/Technical confirmation. HARD is blocked until QARA/Regulatory and Clinical/Medical clear the specific wording. RESERVED nodes are held in the tree and are not built, not indexed and not linked. This register is a production input. It does not approve any claim, does not alter the intended purpose of the device, and does not replace Regulatory, Clinical or Legal review.

## Control rules (verbatim)

> METADATA CONTROL RULE   A title tag, a meta description and a URL slug are external statements. They are quoted in search results, shared in messages and reproduced verbatim in AI answers, where they detach from the page that qualified them. Each one passes the same claims review as body copy, and the prohibited list applies in full: diagnostic framing, outcome claims, treatment and timing claims, trend language, "approved" in relation to FDA, risk stratification and economic claims.
